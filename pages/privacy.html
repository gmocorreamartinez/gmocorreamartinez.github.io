Política de Privacidad

Tu privacidad es fundamental. Aquí te explico cómo protejo tus datos.

Última actualización: Agosto 2025

Introducción

Esta Política de Privacidad describe cómo Guillermo Correa Martinez ("yo", "mi", o "el sitio") recopila, usa y protege la información que proporciones cuando uses este sitio web (gmocorreamartinez.github.io) y sus servicios relacionados.

Al usar este sitio web, aceptas las prácticas descritas en esta política. Si no estás de acuerdo con esta política, por favor no uses el sitio.

Información que Recopilamos

Información que proporcionas voluntariamente:

  • Formulario de contacto: Nombre, apellido, email, empresa, asunto, mensaje y preferencias de comunicación
  • Comunicación directa: Cualquier información que incluyas en emails o mensajes directos
  • Suscripciones: Email para recibir actualizaciones (solo si lo solicitas)

Información recopilada automáticamente:

  • Datos técnicos: Dirección IP, tipo de navegador, sistema operativo, páginas visitadas
  • Cookies: Preferencias del sitio y datos de análisis básicos
  • Logs del servidor: Información estándar de acceso web (proporcionada por GitHub Pages)
